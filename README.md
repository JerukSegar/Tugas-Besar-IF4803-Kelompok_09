# Tugas-Besar-IF4803-Kelompok_09
Rancanglah multi-linked list yang memodelkan dokter, pasien, dan hubungan diantara mereka. Seorang dokter dapat menangani banyak pasien, dan satu pasien hanya ditangani oleh satu dokter. Program anda harus mengimplementasikan daftar dan semua fitur yang tercantuk di bawah ini.
